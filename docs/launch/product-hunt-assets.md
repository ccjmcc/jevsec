# Product launch assets

## Name
JevSec — Security Decision Engine

## One-line description
Self-hosted AI security decision engine for behavior-based web threat triage.

## Short description
Compare explainable rules with local System-One model judgments, calibrate decisions using a held-out validation set, and inspect structured attack stories without sending request data to a cloud inference provider.

## Tagline options
- Local AI for explainable web behavior triage.
- Turn access logs into evidence, not automatic blocks.
- Rules, local models, and calibrated human review in one dashboard.
